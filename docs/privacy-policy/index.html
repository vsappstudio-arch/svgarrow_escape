What this app is

ARROWW is a single-player puzzle game. It does not create user accounts, does not require sign-in, and does not use analytics, advertising, or cloud services of any kind.

Data storage

All game progress — unlocked levels, star ratings, coins, and your app settings — is stored only on your device, using standard local app storage. This data is never transmitted anywhere and is not backed up to any account or cloud service controlled by us.

Uninstalling the app permanently deletes this data. There is no server-side copy to separately request deletion of, because none exists.

Internet access

The app requests the Internet permission for exactly one purpose: detecting whether your device currently has a working internet connection, so the in-app Shop can show accurate offline messaging. This is done with a basic connectivity check and does not send any of your data anywhere, collect any information about you, or communicate with any server operated by us.

Notifications

ARROWW can show occasional local reminder notifications (currently up to twice a week) to invite you back to play. These notifications are generated entirely on your own device — nothing is sent to or received from a server to produce them. You can turn this off at any time in the app's Settings screen, and Android's own notification permission controls apply as well.

Third parties

ARROWW does not integrate any third-party analytics, advertising, crash-reporting, or tracking services. No data collected by (or about) you is shared with, or sold to, any third party, because no such data is collected in the first place.

Children's privacy

ARROWW does not knowingly collect personal information from anyone, including children, because it does not collect personal information from any user at all.

Changes to this policy

If a future version of ARROWW adds functionality that changes any of the above — for example, an optional cloud-save feature — this policy will be updated first, and the updated version will describe exactly what changed, before that functionality is enabled.
